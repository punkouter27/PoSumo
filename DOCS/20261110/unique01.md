## Run

`pwsh -File Training/Run-Unique01.ps1` with the Unity Editor CLOSED. It builds the four
donor envs in batch mode, prunes the event-less `*_intentinit` staging runs, stages the
warm starts, starts TensorBoard (6006, `Training/results`), then runs two fighters at a
time, 2 env players each, 5 minutes from env start, graceful close. Estimate: 8 waves x
~7 min = ~56 min, plus ~12 min of env builds. Machine: 12 logical cores, 15.9 GB.
Status per run: `unique01_status.json`.

Expected yield at the last measured rate (~750k steps/h on 2 envs): ~60k steps each.
That is a corrective nudge for the new start pose and a first own-name brain for each
placeholder, not a trained-to-gate policy: no run will meet the 100-episode graduation
gate in 5 minutes. Judge each on ELO shape from 1200.
